# Changelog - BraveType - Font Manager Tool

All notable changes to **BraveType - Font Manager Tool** will be documented in this file.

## [1.0.0] - 2026-08-03 (Initial Release)

### Added
- **Instant Launch & Cache Engine**: Integrated `fontCache.json` with file timestamp validation (`mtimeMs`).
- **Progressive Font Scanner**: Windows font directory scanner supporting 2000+ fonts in background.
- **Transcity Brand Typography**: Signature visual identity for Brave Studios.
- **Premium Startup Splash Screen**: Mechanical keyboard typing animation with Web Audio API sound synthesizer.
- **Manual Collections**: Create, Rename, Duplicate, Delete, and Sort A-Z.
- **Developer Mode**: Detailed OpenType metrics, PostScript names, and glyph counts.
- **Offline Backup & Restore**: Export and Import JSON backup configuration files.
- **Electron Security Hardening**: Context Isolation, CSP header enforcement, path validation, and window navigation blocking.
