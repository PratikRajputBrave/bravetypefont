Installation Walkthrough

Windows SmartScreen Installation Guide

When installing BraveType on Windows, you may encounter the "Windows protected your PC" SmartScreen prompt. Here is why it appears and how to complete setup safely in 4 easy steps.

Why does Windows SmartScreen display a warning?

BraveType is an open-source tool. Commercial EV Code Signing Certificates cost $500+/year. Because this binary is brand new and non-commercial, Windows SmartScreen flags it as "unknown publisher" by default. BraveType is 100% clean, open-source, and malware-free. You can verify our source code or SHA256 checksum at any time.

1

Download Installer

Click the download button to get the official installer from Google Drive or GitHub releases.

2

Launch Executable

Double-click the downloaded file in your Windows Downloads folder to start installation.

3

Click "More Info"

When the blue "Windows protected your PC" window appears, click the "More info" link text under the title.

4

Click "Run Anyway"

A new button labeled "Run anyway" will appear at the bottom right. Click it to launch setup!
