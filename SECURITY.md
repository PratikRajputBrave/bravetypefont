# Security Policy - BraveType - Font Manager Tool

## Security Protections

BraveType implements modern Electron security best practices:
- **Context Isolation**: Enabled
- **Node Integration in Renderer**: Disabled
- **Content Security Policy (CSP)**: Enforced strict local-resource policies
- **Navigation Guard**: Blocks external navigation & popup windows
- **Input & Protocol Sanitization**: All file paths and IPC channels are validated and normalized

## Reporting a Security Vulnerability

If you discover a security issue, please contact **Brave Studios**.
